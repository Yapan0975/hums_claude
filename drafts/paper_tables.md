**Notes.**
- *Representation* uses the labels { TSDF, SDF, Voxel, 3DGS, Scene Graph } as instructed; combined cells (e.g., row 1 "TSDF + Dirichlet evidential") denote a layered backbone where the second component augments the first.
- *Uncertainty Modeling* taxonomy: { None, Point Estimate, Bayesian Filter, Dirichlet Evidential }. Row 5's "Iterative per-voxel Bayes filter (unspecified)" is in spirit Bayesian Filter but is graded so because R2 [jiao2024r2] does not publish the update formula (audit S1/S2).
- *Open-Set Support* taxonomy: { ✗, Task-driven, Vocab-CLIP, Vacuity-based }. Row 4 is Task-driven; row 2 is Vocab-CLIP at the *front-end module level* only (background model is closed-set).
- *Loop Closure* taxonomy: { ✗, Geometric only, Semantic + Geometric, Vacuity-conditioned }. Hydra [hughes2022hydra] inherits hierarchical LCD into Khronos; we list Khronos as "Yes (loop closures inside factor graph)".
- *Lifelong Maintenance* taxonomy: { ✗, Time window, Change detection, Vacuity-decay }. Khronos uses the latter two; we cleanly use the third with one scalar.
- *Dynamic Scene Handling*: { ✗, 4D factorization, Implicit via vacuity, Tracker }.
- *Real-Time on Jetson*: { ✗, ✓ (but fps), ✓ ≥ 5 Hz }. "[NR]" denotes a number the original paper did not publish (e.g., R2 reports only RTX 3080 Ti latency, not Jetson). "[TBD-RQ5]" is a deliberately blank cell to be filled in our §IV.G.
- All sensor-stack abbreviations follow the original papers; "LiDAR-only" for row 1 means deployment-time inputs only — an RGB-supervised prior may be used at training time per §III.B.

**Discussion.** Row 1 and rows 2 – 4 are *methodologically orthogonal*: Khronos owns the dynamic-scene axis through explicit 4D factorisation [schmid2024khronos]; Clio owns the task-driven open-set axis through Information Bottleneck compression of CLIP primitives [maggio2024clio]; GS-LIVO owns the photo-realistic representation axis with Jetson-deployable 3DGS [hong2025gslivo]. EvidLife-Map does not contest any single axis at its own SOTA point; it instead reuses one statistical quantity — Dirichlet vacuity — across calibration, open-set OOD, vacuity-conditioned loop closure, and vacuity-driven decay, where the three threat systems each maintain a separate auxiliary mechanism per task. The row-5 baseline R2 [jiao2024r2] sits below all four as the system that *attempts* outdoor LiDAR-only MSM but leaves the per-voxel Bayes filter unspecified and has no open-set / loop / decay machinery (audit S1/S2/S5/T1-T4); row 6 nvblox [millane2024nvblox] is the geometric substrate both R2 and our system fork from, so it bounds what "geometric-only" lower-bound performance looks like. This matrix therefore positions our work as the *integrating* contribution: rather than replacing any one threat system, we close R2's four open gaps with a single Dirichlet-derived signal and show that the three remaining axes (open-set, loop closure, dynamic-implicit) all admit a vacuity-based answer.

ROWS ARE CHRONOLOGICAL; COLUMNS TRACE THE MATHEMATICAL BACKBONE, UNCERTAINTY QUANTIFICATION, LEARNABILITY, OPEN-SET CAPABILITY, REPORTED BEST mIoU, REPORTED CALIBRATION ECE, AND WHETHER THE UNCERTAINTY SIGNAL IS REUSABLE BY DECAY / LOOP-CLOSURE CONSUMERS. | 1 | S-BKI [gan2020sbki] | RA-L 2020 | Kernel Bayesian (sparse spatial kernel + Dirichlet–Categorical conjugate; closed-form weighted-count update) | Per-voxel Dirichlet variance (Eq. 10); single global `l` length-scale; `σ_0 = 1` | ✗ (kernel `l` and prior `α_0` are hand-set: KITTI 0.3 m, SemKITTI 0.4 m) | ✗ (closed-set 19 classes; variance rises on unseen but no AUROC reported) | KITTI seq 15 57.1 %; SemKITTI Test 51.3 %; SemKITTI Train 85.3 %; SemKITTI Val 57.4 % | [NR] | ✗ (variance contaminated by neighbour evidence through the spatial kernel) |

| 4 | **EvidLife-Map (ours)** | IROS 2027 (target) | **Dirichlet Evidential Learning** — per-voxel α ∈ R^{C+1} with α_k = e_k + 1; closed-form conjugate accumulation (Eq. 4 of paper); no spatial kernel | **Vacuity** `u_v = (C+1)/S_v ∈ (0,1]` (Eq. 2 of paper); single scalar per voxel | ✓ (last-layer Cylinder3D fine-tuned with EDL loss, Eq. 5; per-class evidence learnable) | ✓ (vacuity native OOD score; explicit "unknown" channel; H2 target AUROC ≥ 0.80 on SemKITTI 14/5 split, RQ2) | [TBD-RQ1] vs ConvBKI 77.7 % on SemKITTI seq 08; H1 target ≥ +2 mIoU and ≥ −20 % ECE vs R2-reimpl | native (Eq. 6 of paper; H1 target ≥ −20 % vs R2-reimpl baseline); [TBD-RQ1] | ✓ (one vacuity scalar reused as: (i) M1 calibration & OOD score, (ii) M2 entropy descriptor channel, (iii) M3 decay clock τ(u_v); §III.E) |

**Notes.**
- ConvBKI's 77.7 % mIoU is on KITTI Odometry seq 15 (Wilson et al. 2024 Table I, ConvBKI Compound, voxel 0.2 m, depthwise filter 5×5×5); S-BKI fine 77.2 % is the comparable cell. KITTI Odom 15 is the historical BKI benchmark and is distinct from SemKITTI seq 08.
- S-BKI 51.3 % mIoU is on the SemKITTI *Test* set with Darknet-kNN front-end; SemKITTI Val is 57.4 %. The two are reported by the same paper (Gan 2020) and serve different reproduction needs.
- ConvBKI runs at 44.3 Hz on RTX 3090; LatentBKI updates 100 K points in 122.05 ms (≈ 8 Hz at 100 K throughput on the same class of GPU).
- "Reusable for Decay/LC" answers: can the uncertainty signal serve a downstream lifelong-maintenance or loop-closure consumer without recomputation or auxiliary state? Only row 4 ships this property by construction.
- Row 4 placeholders ([TBD-RQ1]) are *deliberately* unfilled; they are the §IV main-result cells to be back-filled after the §7 P2 / P3 experiments per `research_plan.md` v3 §4.

**Discussion.** The lineage shows a strict *capability monotone* on the left half of the table — every successor system gains learnability without losing closed-form tractability (S-BKI's hand-set kernel becomes ConvBKI's 22 learnable kernel parameters, which becomes LatentBKI's learned encoder feeding a closed-form Gaussian-NIW posterior) — but a *stalled* uncertainty axis: variance, variance, latent covariance, and only at row 4 does a *single scalar simplex-level epistemic signal* appear that can be consumed without decoding or neighbour-contamination. EvidLife-Map is therefore not a replacement of the BKI lineage but its evidential extension: row 1's Dirichlet–multinomial conjugacy is preserved (Eq. 4 of paper_v1.md is the same conjugate accumulation that S-BKI uses on its kernel-weighted counts), the spatial kernel is deliberately *dropped* (per §III.B of paper_v1.md, vacuity must be uncontaminated for M2 and M3 to consume it honestly), and the same posterior strength `S_v` that S-BKI used only for normalisation is now elevated to a load-bearing scalar. The "Reusable for Decay/LC" column is therefore the strongest defensible novelty claim: EvidLife-Map is the first BKI-family system whose uncertainty signal is, by construction, the same statistical quantity that drives lifelong decay and loop-closure descriptor entropy.
