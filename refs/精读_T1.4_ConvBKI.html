1 背景：probabilistic vs deep-learning mapping 的鸿沟

机器人感知正处于"经典概率方法"与"现代隐式神经网络"的十字路口。前者可靠但慢、超参靠手调；后者高效但黑盒、跨数据集易崩。Wilson 等人提出 ConvBKI 来弥合这道鸿沟。

1.1 三层困境

  1. Gaussian Process Occupancy Map (GPOM) 闭式推断但 $O(N^3)$，N 大时不可用；
  2. Bayesian Generalized Kernel Inference (BGKI) 把 GP 近似到 $O(\log N)$，但 kernel 手调，每类同核；
  3. 纯学习 端到端 mapping（Semantic MapNet 等）虽然快，却"幻觉"场景—— sim-to-real 跨域时静默崩溃。
"Classical probabilistic solutions offer reliable and trustworthy performance at the expense of longer run-times and un-optimized, hand-tuned parameters. In contrast, modern deep learning methods achieve higher performance and improved latency due to optimization in an implicit space but lose the ability to generalize to new data." —— §I

1.2 off-road perception 必须有不确定性

越野场景下的"负障碍"（坑、悬崖）是没有数据点的——若模型没有方差度量，就会自信地说"前方有路"，造成事故。不确定性量化不是 nice-to-have，是 safety-critical 必备。

🎯 一句话定位
ConvBKI = 把 Semantic-BKI 的"每核更新"重写成 depthwise 3D 卷积，每类学一个 ellipsoidal kernel（22 参数），44.3 Hz 实时，per-voxel Dirichlet variance 仍然 closed-form 可算。

2 论文的三大贡献 + 工程贡献

① 新 NN 层 ConvBKI

把 Bayesian Kernel Inference 重写成可反向传播的 depthwise convolution layer，结合 probabilistic 推理与可微编程。

② 实时 explicit 不确定性

per-voxel 闭式 Dirichlet 方差 (式 10)，能在 >10 Hz 速率下产出 explicit probabilistic semantic map。

③ 大规模对比实验

对 probabilistic baseline（S-BKI / S-CSM / BGKOctoMap-CRF）和 learning baseline（Semantic MapNet GRU/LSTM/Linear）都做了 head-to-head 对比。

④ 开源 ROS 包 + 越野数据集

github.com/UMich-CURLY/BKI_ROS。新越野数据集（保密未公开）展示 unseen-class 下 variance 升高的"诚实退化"行为。

🏆 核心数字成果
  • KITTI Odom 15: 77.7% mIoU（ConvBKI Compound），比 S-BKI fine (77.2%) 高 0.5%，比 S-BKI (0.2m) baseline 76.5% 高 1.2%；
  • 推理频率从 S-BKI 的 0.6 Hz → ConvBKI 44.3 Hz（~74× 加速）；
  • 参数量：仅 22 个（Semantic MapNet 是 1.96M ~ 2.04M，差 ~100,000×）；
  • CarlaSC → SemanticKITTI sim-to-real：ConvBKI 26.7% → 24.2% （直接），SMNet 35.4% → 23.9%；
  • swap segmentation 网络后：ConvBKI 46.6% vs SMNet 4.6%（差 10×）；
  • Ablation：filter 5×5×5 @ 0.2 m → 216.8 Hz，mIoU 59.3%。

3 方法总览（ASCII 架构图）

ConvBKI 是一个 recurrent neural layer，输入是带语义概率的点云，输出是 per-voxel Dirichlet concentration parameters $\alpha^c_*$。

┌─────────────────────────────────────────────────────────────────────┐ │ INPUT │ │ 点云 P_t = {(x_i, y_i)} y_i ∈ Δ^C (softmax 语义概率 C 类) │ └─────────────────────────────────────────────────────────────────────┘ │ ▼ ① 语义分割网络 (SPVCNN / DilatedCNN — off-the-shelf) │ ▼ ② Voxel Discretization Eq. (13) F^c_* = Σ_i 𝕀(* , i) · y_i^c (sum semantic mass) │ ▼ ③ Depthwise 3D Conv Eq. (14) α^c_{*,t} = α^c_{*,t-1} + Σ_{n,o,p} K^c_{n,o,p} F^c_{h+n,i+o,j+p} (per-class kernel K^c — sparse kernel function, 2 params: l_h, l_v) │ ▼ ④ Local Map Shift §V (only integer-voxel translation, R + s_t) │ ▼ ⑤ Dirichlet Statistics Eq. (10) η_* = Σ α^j_* E[θ^c_*] = α^c_* / η_* ← maximum-likelihood class V[θ^c_*] = α^c_*/η_* · (1 - α^c_*/η_*) / (1 + η_*) ← variance │ ▼ OUTPUT: per-voxel (semantic mean, variance) — both closed-form │ ▼ Trained end-to-end via gradient descent on NLL loss

3.1 与 S-BKI 的形式对应关系

核心观察：S-BKI 的更新式 (式 9)

$$\alpha^c_{*,t} = \alpha^c_{*,t-1} + \sum_{i=1}^{N_t} k(x_*, x_i) y^c_i \tag{9}$$

可以 rewrite 为 depthwise convolution（式 14）：

$$\alpha^c_{*,t} = \alpha^c_{*,t-1} + \sum_{n,o,p} K^c_{n,o,p}\, F^c_{h+n, i+o, j+p} \tag{14}$$

其中 $F$ 是 voxelized semantic volume，$K^c$ 是 per-class filter，将 kernel function $k^c$ 在 filter 网格上离散化得到（式 15）。这样 GPU 可并行处理，且 kernel 参数可学习。

💡 三处关键创新
  1. 每类独立 kernel $k^c$：不再像 S-BKI 全部类共用一个 spherical kernel；
  2. Compound kernel（水平 × 垂直）：用 $k^c = \kappa^c_h(\Delta_{xy}) \cdot \kappa^c_v(\Delta_z)$ 建模 ellipsoidal 几何，例如 pole 类竖直长水平短；
  3. Continuous Categorical likelihood（式 12）：likelihood 接受 softmax 输入而非 one-hot，避免信息损失。

4 关键模块拆解

4.1 Bayesian Kernel Inference 复习

Vega-Brown et al. (2014) 提出，BKI 通过 positional kernel $k(x_i, x_*)$ 把"近邻观测"耦合到 query voxel：

$$p(y_i | x_i, \theta_*, x_*) \propto p(y_i | \theta_*)^{k(x_i, x_*)} \tag{2}$$

Kernel 必须满足：$k(x,x) = 1\ \forall x$ 且 $k(x, x_*) \in [0, 1]\ \forall x, x_*$ （式 3）。

4.2 Categorical likelihood + Dirichlet conjugate prior

语义类标号 $c \in \{1, \dots, C\}$，one-hot 观测 $y_i$：

$$p(y_i | \theta_i) = \prod_{c=1}^C (\theta^c_i)^{y^c_i} \tag{1}$$

取 Dirichlet 先验 $\mathrm{Dir}(C, \alpha_0)$ 与上式共轭，由 Bayes 法则推出闭式：

$$p(\theta_* | x_*, D) \propto \prod_c (\theta^c_*)^{\alpha^c_* + \sum_i y^c_i k(x_i, x_*) - 1} \tag{8}$$

即式 (9) 的 weighted-count update。

4.3 Sparse Kernel

ConvBKI 沿用 Melkumyan & Ramos 的 sparse kernel（同 S-BKI）：

$$\kappa(d) = \begin{cases} \sigma_0\left[\frac{1}{3}\left(2 + \cos(2\pi \frac{d}{l})(1 - \frac{d}{l}) + \frac{1}{2\pi}\sin(2\pi \frac{d}{l})\right)\right], & d < l \\ 0, & d \geq l \end{cases} \tag{11}$$

其中 $d = \|x_i - x_*\|_2$，$l$ 为 length-scale。$\sigma_0 = 1$（必须，以满足式 3）。kernel 在 $d=0$ 处为 1，$d = l$ 处衰减到 0。

4.4 Compound kernel（核心创新）

真实物体几何形状有方向性。ConvBKI 用 水平 × 垂直 拆分：

$$k^c\left(\begin{bmatrix}x_i^1\\x_i^2\\x_i^3\end{bmatrix}, \begin{bmatrix}x_*^1\\x_*^2\\x_*^3\end{bmatrix}\right) = \kappa^c_h\left(\left\|\begin{matrix}x_i^1 - x_*^1\\x_i^2 - x_*^2\end{matrix}\right\|_2\right) \cdot \kappa^c_v\left(\|x_i^3 - x_*^3\|_2\right) \tag{16}$$

每类 2 个 length-scale 参数 ($l_h^c, l_v^c$)，共 $2C$ 个参数。对 SemanticKITTI 11 类共 22 参数。

4.5 Dirichlet 统计输出

$$\eta_* = \sum_{j=1}^C \alpha^j_*,\quad \mathbb{E}[\theta^c_*] = \frac{\alpha^c_*}{\eta_*},\quad \mathbb{V}[\theta^c_*] = \frac{\alpha^c_*/\eta_*\,(1 - \alpha^c_*/\eta_*)}{1 + \eta_*} \tag{10}$$

variance 的物理含义：观测越多（$\eta_*$ 越大），variance 越小；当某 voxel 完全未观测时（$\eta_* \approx C\epsilon$），variance 自然最大（uniform prior）。

4.6 Local mapping (§V)

问题：global map 查询是瓶颈，O(occupied voxels) 线性增长。解决方案：

  1. 维护固定大小的 dense local map $L_t \in \mathbb{R}^{D_C \times D_X \times D_Y \times D_Z}$；
  2. ego-vehicle 每移动整数个 voxel ($\nu_{t,t-1}$，式 18) 时整体 shift map；
  3. 余下的连续偏移 $s_t = \psi_t - \Delta r \lfloor \psi_t / \Delta r \rceil$（式 19）记录在 pose 中，对 input point cloud 做旋转 + 平移；
  4. lossless propagation：避免累积近似误差导致 voxel blur。
⚠️ 设计权衡
Local mapping 不做 loop closure——voxel 离开局部窗口就被 discard，重新进入时重设为 prior。这对仅做 short-horizon planning 的应用是可接受的，但对 lifelong mapping 是缺陷。

4.7 训练

  • Loss：weighted Negative Log-Likelihood，而非常见的 cross-entropy（论文 §IV.B）；
  • Optimizer：Adam, lr = 0.007, 1 epoch；
  • Input：$\tau = 10$ 帧；
  • Filter：$f = 5$，分辨率 0.2 m；
  • 训练数据：仅需 semantic segmentation GT，不需要 3D map GT（这是相对 Semantic MapNet 的大优势）。

7.3 Robustness to label noise (Fig. 10)

把语义 GT 替换为随机噪声不同比例（0% ~ 100%）：

  • 低噪声 (<30%)：ConvBKI 的 spatial smoothing 显著抑制噪声，Map GT 准确度远高于 Input GT；
  • 高噪声 (>50%)：update 被噪声主导，准确度急剧下降；
  • variance 同时升高，提供"何时不要信任 map"的诊断信号。

7.4 Free space sampling (Fig. 11)

免费空间采样频率 vs resolution：0.1 m 分辨率 free space sampling 仍可保持 >10 Hz。Voxel grid insertion 在 10M 点时仍 >10 Hz。ConvBKI 自身的 update 复杂度只与 filter size 和 map size 相关，与 input 点数无关。

7.5 Local vs global mapping (Fig. 12)

Global map propagation 时间随 occupied voxels 线性增长，local map 是常数。是论文实现 sustained real-time 的关键工程优化。

8 局限性

✅ 论文承认的优势
  • 22 参数（极轻）+ 44.3 Hz 实时；
  • per-voxel 闭式 variance，可量化不确定性；
  • 对 segmentation noise 鲁棒（spatial smoothing）；
  • 仅需 segmentation GT（不需 3D map GT）；
  • swap segmentation network 不影响 kernel（46.6% mIoU vs SMNet 4.6%）；
  • 越野 unseen class 时 variance 自动升高。
⚠️ 论文承认的局限
  • 不建模 dynamic objects：行人 / 车辆移动会留 trace；BEV 精度受损（pedestrian precision 10.5%）；
  • 不建模旋转：depthwise conv kernel 在所有方向相同，对斜坡 / 非结构化环境不友好；
  • 无 loop closure：local map 出窗即丢；
  • kernel 训练有偏：在 over-fit 的 segmentation 上训出的 kernel 平滑能力弱；
  • 对 systematic error 无能为力：若 segmentation 一直把 sidewalk 误标 road，ConvBKI 无法纠正。

9 与 EvidLife-Map 的关系（关键技术拆解）

ConvBKI 是 EvidLife-Map 的 RQ1 第一 baseline。这一节是本精读最关键的部分——必须搞清楚 Dirichlet posterior vs Dirichlet evidential 的数学区别，以及在哪些 metric 上我们能赢、可能输。

9.1 数学对比：ConvBKI vs EvidLife-Map evidential head

9.2 "quantifiable uncertainty" 的具体定义

ConvBKI 论文中的 "quantifiable uncertainty" 仅指式 (10) 的 per-voxel Dirichlet 方差。这是一个 in-distribution 不确定性度量，不是 epistemic / aleatoric / OOD 的标准 disentangle。论文也承认（§VI.B "Reliability"）："Robustness to epistemic or systemic uncertainty is more difficult for ConvBKI to capture"。EvidLife-Map 的 Dirichlet vacuity 在数学上是 $C/S$，这两个量在大 $S$（多观测）极限下趋势一致，但小 $S$ 时 vacuity 偏向 OOD detection，variance 偏向 frequentist 置信。

9.3 哪些 metric 我们可能赢 / 可能输

✅ 我们可能赢的
  • RQ2 open-set AUROC：ConvBKI 的 variance 没在 OOD task 上 train，AUROC 估计 ~0.5-0.6（接近随机）；evidential 经 KL 正则压抑 false confidence，目标 ≥ 0.85；
  • ECE (RQ1)：ConvBKI NLL 训练对 calibration 不直接优化；EDL loss 含 KL 正则强制 align expected probability 与 frequency；
  • RQ4 lifelong：ConvBKI local map 出窗即丢，无 forgetting 概念；evidential vacuity decay 是天然的 forgetting 信号；
  • RQ3 traversability：vacuity 在路面噪声下持续低，ConvBKI variance 易受 noise 干扰飙高。
⚠️ 我们可能输的
  • mIoU (RQ1)：ConvBKI Compound 在 KITTI Odom 15 已经达 77.7%（vs S-BKI 77.2%），属于 SOTA 水平，evidential head 若仅替换 last layer 不易显著提升；
  • 推理速度：22 参数 + depthwise conv = 44.3 Hz（dense map 时），evidential head 增加全连接层，可能慢 1.5-2×；
  • 训练稳定性：EDL loss 比 NLL 难训，需要 KL warm-up。

9.4 实现：是否开源？自跑 / published numbers？

  • 开源：✅ ROS package at github.com/UMich-CURLY/BKI_ROS（包含 SemanticKITTI / RELLIS-3D 例程）；
  • 训练代码 ConvBKI（非 ROS）：需要确认，看 paper 第一作者 Joey Wilson 的 GitHub；
  • 推荐：自跑（self-reproduced） KITTI Odom 15 和 SemanticKITTI seq 8 上 ConvBKI Compound 0.2 m / f=5 的 mIoU + ECE + 我们补的 AUROC。Published numbers 不含 ECE 和 AUROC（论文未报告），所以为了公平比较必须自跑；
  • 越野数据集（Neya）：不公开，所以 §VII 的结果无法重复——这是 ConvBKI 论文的一个 weakness，我们 RQ3 可用 RELLIS-3D + RUGD 替代；
  • 注意：ConvBKI 训练 lr=0.007 / 1 epoch / kernel init l=0.5 m 是 Wilson 的设置；EvidLife-Map 报告时必须 reproduce 同 hyperparameter 否则不公平。

9.5 EvidLife-Map 借鉴 ConvBKI 的设计

三处可直接借鉴：(1) depthwise conv 实现 BKI——可保留作为 spatial smoothing 模块，evidential head 接在其上；(2) compound kernel——pole/road 几何先验对所有 BKI 系都有效；(3) local map shift——lossless integer-voxel shift 避免 propagation blur，对我们的 voxel decay 长期记忆同样重要。

⚠️ 技术诚实
ConvBKI 是 RQ1 上最 fair 的 baseline——同 BKI 谱系、同输入（点云 + 语义概率）、同输出（per-voxel 概率 + variance），唯一差别就是后端 head（Dirichlet posterior vs Dirichlet evidential）。如果我们在 mIoU 上不能击败 ConvBKI，就只能靠 ECE / AUROC / decay 的"任务集合"打赢——这是 EvidLife-Map 的真正卖点（一个 vacuity 标量同时承担 3 项任务），而不是单一 mIoU。

10 总结

10.1 一句话总结

ConvBKI 把 S-BKI 的 weighted-count Bayesian update 重写为可微分的 depthwise 3D convolution，每类一组 ellipsoidal kernel 参数（共 22 个），在 SemanticKITTI 上以 44.3 Hz 实时输出 per-voxel Dirichlet 类概率与方差，比 S-BKI 在 mIoU 上略胜（77.7% vs 77.2%）但速度快 ~74×；最大亮点是 swap segmentation network 后仍能保持性能（46.6% vs SMNet 4.6%）。

10.2 对 EvidLife-Map 的三个核心 takeaway

  1. ConvBKI 的 variance ≠ vacuity——这是论文"quantifiable uncertainty"宣称的 limit，我们的 EDL 框架在 OOD AUROC 上有结构性优势；
  2. per-class compound kernel 是 strong design——值得在 EvidLife-Map 的 spatial smoothing 模块沿用；
  3. 22 参数是个 reality check——若我们的 evidential head 增到 1M 参数还输给 22 参数的 ConvBKI，那就是设计失败。

10.3 实现注意（写进 RQ1 protocol）

  • 使用 ConvBKI Compound 0.2 m + f=5 作为默认配置；
  • SemanticKITTI seq 8 (valid) 报告 mIoU + ECE + AUROC（后两者论文未报）；
  • 同 segmentation 输入 SPVCNN，hyperparameters: lr=0.007, 1 epoch, $\tau=10$, $l_{init}=0.5$；
  • local map size 与 EvidLife-Map 对齐 ([-25.6, -25.6, -2.0] → [25.6, 25.6, 1.0] m)；
  • ROS 节点路径：github.com/UMich-CURLY/BKI_ROS。
