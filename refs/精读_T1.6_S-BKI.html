1 背景：从 BGKOctoMap 到 S-BKI

机器人 mapping 历史上是 occupancy grid → continuous occupancy → semantic occupancy。S-BKI 是 把 Doherty et al. 2017/2019 的 BGKOctoMap（二元占用）正式扩展到 K 类语义的里程碑工作，是后续 evidential 谱系（包括 ConvBKI、Latent-BKI 和我们 EvidLife-Map）的共同祖先。

1.1 离散 vs 连续语义 mapping 的鸿沟

  1. 离散占用 + CRF post-processing：Yang et al. [9] 用 CRF 后处理。问题：CRF 只能修改已占据 voxel 的标签，不能 fill gaps；
  2. Continuous occupancy via GP (GPOM)：可填洞，但 $O(N^3)$，K 类扩展走 one-vs-rest 又乘 K；
  3. Hilbert maps：线性时间 update，但 logistic regression 无 closed-form variance。

1.2 BGKOctoMap 是基础

Doherty et al. [21] (TRO 2019) 用 Vega-Brown et al. [31] 的 Bayesian Kernel Inference 把 Bernoulli + Beta 共轭从 counting sensor model 推广到连续 occupancy。复杂度从 GP 的 $O(N^3)$ 降到 $O(\log N)$。S-BKI 把它从 binary → multi-class。

🎯 一句话定位
S-BKI = BGKOctoMap 的语义版。Categorical likelihood + Dirichlet 共轭先验 把 BKI 扩到 K 类，给每个 voxel 一个闭式 Dirichlet posterior（mean + variance）。是 ConvBKI / Latent-BKI / 本文 evidential mapping 的共同数学起点。

2 论文的三大贡献

① 统一概率模型

用单一 Dirichlet posterior 同时建模 occupancy + 语义概率；K=2 时自动 revert 到 BGKOctoMap。

② 开源实现（multi-thread + vectorized）

C++ on laptop CPU，2 Hz 实时（2020 标准）；基于 LAMA library + ROS + PCL。

③ 大规模评估

KITTI（stereo 相机 + 8 类）+ SemanticKITTI（LiDAR 64-beam + 19 类）+ Stanford 2D-3D-S（occupancy AUC）+ Cassie bipedal robot 实地实验。

④ 与 CRF 类方法的实证对比

S-BKI 显著超越 Yang et al. CRF 方法和 BGKOctoMap-CRF（自家构造的 strong baseline）。

🏆 核心数字成果
  • KITTI seq 05：S-BKI 46.0% mIoU vs Yang 40.2%（+5.8）；
  • KITTI seq 15：S-BKI 57.1% mIoU vs Yang 50.0%（+7.1）；
  • SemanticKITTI Test：S-BKI (w/ Da.-kNN) 51.3% mIoU vs Da.-kNN 47.5%（+3.8）；
  • SemanticKITTI Training：S-BKI 85.3% vs S-CSM 83.3% vs Da.-kNN 79.6%；
  • SemanticKITTI Validation: S-BKI 57.4% vs S-CSM 56.2% vs Da.-kNN 52.8%；
  • 占用 AUC：S-BKI 0.7801（同 BGKOctoMap，证明 K=2 reverts）；
  • Runtime：KITTI S-BKI 0.36 s/scan vs Yang 4.41 s/scan（12.3× 加速）；SemanticKITTI S-BKI 1.67 s/scan vs S-CSM 9.48 s/scan。

3.1 关键设计

  • Octree of grids：每个 block 是 octree of grids；test data 用 block 的"extended block"（邻接 block）的所有数据训练；
  • K=2 时退化为 BGKOctoMap——理论 + 实验都验证（Table V AUC 0.7801 与 BGKOctoMap 完全相同）；
  • Multi-threading + vectorization：8-core i7 laptop 即可 ~2 Hz。
💡 核心洞察
S-BKI 的 update 是 BKI 推导出来的 closed-form Bayesian update（式 9），与"加权 NW 核回归"或"线性 opinion pooling"形式相似但不等价（论文 §VI 讨论）。这与 evidential learning 是同一族 Dirichlet 概率方法，只是从 frequentist Bayesian update 而非 NN evidential output 推出。

4 关键模块拆解：S-CSM → S-BKI 推导

4.1 Semantic Counting Sensor Model (S-CSM)

K 类语义，cell $j$，one-hot 观测 $y_i = (y^1_i, \dots, y^K_i)$，$\sum_k y^k_i = 1$。Categorical likelihood：

$$p(y_i | \theta_j) = \prod_{k=1}^K (\theta^k_j)^{y^k_i} \tag{1}$$

取 Dirichlet 共轭先验 $\mathrm{Dir}(K, \alpha_0)$（$\alpha_0 = (\alpha^1_0, \dots, \alpha^K_0)$, $\alpha^k_0 \in \mathbb{R}_+$）。Bayes 法则给出闭式 posterior：

$$\alpha^k_j := \alpha^k_0 + \sum_{i,\, x_i \in \mathrm{cell}\, j} y^k_i \tag{2}$$

即 S-CSM。统计量：

$$\hat{\theta}^k_j = \frac{\alpha^k_j - 1}{\sum_k \alpha^k_j - K},\quad \alpha^k_j > 1 \tag{3}$$
$$\mathbb{E}[\theta^k_j] = \frac{\alpha^k_j}{\sum_k \alpha^k_j},\quad \mathbb{V}[\theta^k_j] = \frac{\alpha^k_j/\sum_k\alpha^k_j \cdot (1 - \alpha^k_j/\sum_k\alpha^k_j)}{\sum_k \alpha^k_j + 1} \tag{4}$$

K=1（free）和 K=2（occupied）时，S-CSM 就是 binary counting sensor model（即 BGKOctoMap 的离散版本）。

4.2 Bayesian Kernel Inference (Vega-Brown et al. 2014)

BKI 的核心是把 likelihood $f(y_i) = p(y_i|\theta_i)$ 扩展为 extended likelihood $g(y_i) = p(y_i|\theta_*, x_i, x_*)$，要求两者 KL divergence 有界。最大熵解：

$$\prod_{i=1}^N p(y_i | \theta_*, x_i, x_*) \propto \prod_{i=1}^N p(y_i | \theta_*)^{k(x_*, x_i)} \tag{5}$$

其中 $k: X \times X \to [0, 1]$ 是空间核函数（kernel 不必正定也不必对称）。

4.3 S-BKI 推导（论文最核心一段）

Categorical likelihood 套入 (5)，加 Dirichlet 先验：

$$p(\theta_* | x_*, D) \propto \left[\prod_{i=1}^N \prod_{k=1}^K (\theta^k_*)^{y^k_i}\right]^{k(x_*, x_i)} \prod_{k=1}^K (\theta^k_*)^{\alpha^k_0 - 1} = \prod_{k=1}^K (\theta^k_*)^{\alpha^k_0 + \sum_{i=1}^N y^k_i\, k(x_*, x_i) - 1} \tag{8}$$

正比于 $\mathrm{Dir}(K, \alpha_*)$，其中 核心更新式：

$$\alpha^k_* := \alpha^k_0 + \sum_{i=1}^N k(x_*, x_i)\, y^k_i \tag{9}$$

与 S-CSM (2) 的核心差别：不再只看落入 cell 的点，而是用 kernel weight 累加所有邻近点。这正是 ConvBKI 把它重写为 depthwise conv 的源头。

4.4 Sparse kernel（与 ConvBKI / nvblox 同款）

$$k(x, x') = \begin{cases} \sigma_0\left[\frac{1}{3}\left(2 + \cos(2\pi \frac{d}{l})(1 - \frac{d}{l}) + \frac{1}{2\pi}\sin(2\pi \frac{d}{l})\right)\right], & d < l \\ 0, & d \geq l \end{cases} \tag{10}$$

其中 $d = \|x - x'\|$，$l$ 是 length-scale，$\sigma_0$ 是 signal variance。论文超参（Table I）：

💡 实现细节：extended block
对每个 query block，训练数据来自该 block 的 extended block（相邻 6 个面 block 的并集），即可保证 kernel 半径 $l$ 内的所有点都被纳入计算，避免边界 artifact。

4.5 与 NW kernel regression 的关系（§VI 讨论）

论文明言：S-BKI 把 softmax 输入改成 max 后等价于 NW kernel regression 和 linear opinion pooling，但不完全等价。这个细节对评审重要——若 reviewer 质疑"S-BKI 只是加权平均"，答："不，BKI 是从最大熵推出的 closed-form Bayesian inference，且能给方差，NW 只给点估计。"

7 Ablation：超参敏感性（§V.D, Fig. 5）

7.1 Kernel length-scale $l$

  • $l = 0.01 \to 0.1$：mIoU 急速上升（核太小时类似 S-CSM）；
  • $l = 0.1 \to$ 峰值（KITTI 0.3 m, SemanticKITTI 0.4 m）；
  • 过大：mIoU 缓慢下降（小物体被 oversmoothed）。

论文洞察：LiDAR 数据比 stereo 稀疏，所以 LiDAR 的最优 $l$ 更大（0.4 vs 0.3 m）。这意味着 ConvBKI 让 kernel 可学是个自然 extension。

7.2 Signal variance $\sigma_0$

论文说"mapping performance is insensitive to signal variance over a large scale"——原因是所有类共用同一 $\sigma_0$，影响被 normalize 掉。如果允许类别间变化 $\sigma_0$，效果应该会出现。ConvBKI 正是 explore 了这一方向。

8 局限性（§VI）

✅ 优势
  • 统一概率模型（occupancy + semantic）；
  • K=2 自然 revert 到 BGKOctoMap；
  • 闭式 Dirichlet posterior + variance；
  • 对噪声 segmentation 鲁棒；
  • 开源 + multi-thread；
  • 对 stereo / LiDAR 都适用。
⚠️ 论文承认的局限
  • kernel length-scale 全局共享 + 手调：小物体易 oversmoothed → ConvBKI 正是 fix 这个；
  • 无 hyperparameter 优化框架（Bayesian opt 或 GP）；
  • kernel 与类别 + 几何无关——pole 与 wall 同 kernel 不合理 → ConvBKI Compound kernel 是 fix；
  • 内存与 storage 大：无 pruning；
  • 只支持静态场景：无 dynamic / static 区分。

9 与 EvidLife-Map 的关系（evidential 谱系定位）

S-BKI 是 EvidLife-Map 的 RQ1 第二 baseline，也是 evidential mapping 谱系的祖先。这一节解答：(1) Bayesian spatial kernel 与 evidential 的数学关系，(2) continuous vs discrete 区别，(3) 为什么 ConvBKI 是对 S-BKI 的改进，(4) 我们 evidential 在 S-BKI 谱系中的位置。

9.1 BKI 与 Evidential Learning 的数学关系

关键洞察：BKI posterior 与 evidential output 是 Dirichlet 分布的两种 parameterization。区别在于 $\alpha$ 怎么来：

属性S-BKIEvidLife-Map (evidential)
$\alpha$ 来源$\alpha^k_* = \alpha^k_0 + \sum_i k(x_*, x_i) y^k_i$（核加权计数）$\alpha^k = \mathrm{ReLU}(\mathrm{NN}(\cdot))_k + 1$（NN 输出 evidence）
训练无训练——超参手调EDL loss = $\sum_k (\mathrm{onehot}_k - \mathbb{E}[\theta^k])^2 + \theta^k(1-\theta^k)/(S+1) + \lambda \cdot \mathrm{KL}(\alpha\|\mathrm{Dir}(\vec{1}))$
不确定性度量Dirichlet 方差 $\mathbb{V}[\theta^k]$（式 4，Frequentist）Vacuity $u = K/S$（其中 $S = \sum_k \alpha^k$）
vacuity 在 S-BKI 中？是！ S-BKI 里 $S = \sum_k \alpha^k_0 + \sum_i k(x_*, x_i)$。若 $x_*$ 远离所有观测，$S \to K\alpha_0$，即 $u \to 1$（高 vacuity）。所以 S-BKI 隐式包含了 vacuity 概念，只是没人这么叫
OOD 处理未训练，无 OOD 概念EDL loss 显式惩罚 OOD 的 false confidence
谱系关系S-BKI 是 evidential 的 generative 前传，evidential 是 discriminative 后继——同 Dirichlet posterior 框架，不同推断哲学
💡 数学等价性证明（简化）
若 evidential head 学到的 $\alpha^k_{\mathrm{evid}} = \alpha^k_0 + \sum_i k(x_*, x_i) y^k_i$ 完全等于 S-BKI 的 update，则 vacuity = $K/S$ 与 S-BKI 的 variance 在 $S$ 大时单调对应（vacuity 小 ↔ variance 小）。所以 EvidLife-Map 可以视为"learned BKI"——learnable evidence 替代 hand-crafted kernel weighted count。

9.2 Bayesian spatial kernel 是 evidential 的特例吗？

不完全是。 严格说：

  • S-BKI 的 $\alpha$ 是 analytic Bayesian update（数据通过 likelihood 进入）；
  • EDL 的 $\alpha$ 是 NN regression to evidence（数据通过 loss 进入）；
  • S-BKI 给定先验 + likelihood + kernel 是 closed-form 推断；EDL 是 amortized inference；
  • 两者输出都是 Dirichlet，但 S-BKI 不可学 kernel/likelihood，EDL 全部可学；
  • ConvBKI 正是把 S-BKI 的 kernel 改成可学 → 处于二者之间。

结论：S-BKI ⊂ ConvBKI ⊂ EvidLife-Map（每一步增加更多可学性 + 更明确的 OOD/lifelong handling）。

9.3 Continuous vs Discrete 区别

属性S-CSM (discrete)S-BKI (continuous)
更新规则$\alpha^k_j = \alpha^k_0 + \sum_{x_i \in \mathrm{cell}\, j} y^k_i$$\alpha^k_* = \alpha^k_0 + \sum_i k(x_*, x_i) y^k_i$
独立网格假设是否（空间核耦合）
填洞能力无（局部观测决定）有（kernel 半径内邻居贡献）

EvidLife-Map 选 continuous（继承 S-BKI / ConvBKI）——必须能填洞 + 自适应分辨率，这对 RQ4 lifelong（map decay 后重观测）至关重要。

9.4 为什么 ConvBKI 是对 S-BKI 的改进？

  1. kernel hand-tuned → learned：S-BKI 用同一个 spherical kernel 对所有类，ConvBKI 学 per-class compound kernel（pole 是竖直 ellipsoid）；
  2. CPU O(N log N) → GPU O(1) parallel：BKI 找每个 query 的近邻 (kd-tree) 不可并行；ConvBKI 把 update 表为 depthwise conv，GPU 直接跑；
  3. 0.36 s/scan (CPU) → 22 ms/scan (GPU)：~16× 加速；
  4. KITTI seq 15 mIoU 77.2% → 77.7%：边际涨幅（kernel 学习的额外收益）；
  5. 下游能力同等：variance 量级 + interpretability + 共轭闭式。

  4. 报告新 metric：S-BKI 论文只报 mIoU，必须自跑加 ECE + AUROC（这两项 EvidLife-Map 与 ConvBKI/S-BKI 都未报，是新 contribution）；
  5. SemanticKITTI Test 子集：直接用论文 Table IV 的官方提交结果（S-BKI 51.3% mIoU on test, 19 静态类）作为 published number。

10 总结

10.1 一句话总结

S-BKI 把 BGKOctoMap 的二元 Bayesian Kernel Inference 形式化扩展到 K 类语义（Categorical likelihood + Dirichlet 共轭先验），用一个空间核 $k(x_*, x_i)$ 把"独立网格"假设松弛为"空间平滑"，给每个 voxel 闭式 Dirichlet posterior（mean + variance），K=2 时自动 revert 到 BGKOctoMap；在 KITTI/SemanticKITTI 上比 CRF 类离散方法 mIoU 提升 5-7%，是 evidential mapping 谱系的共同数学起点。

10.2 对 EvidLife-Map 的三个 takeaway

  1. S-BKI 的 $\alpha$ 与 EDL 的 $\alpha$ 是同一种 Dirichlet 参数化——我们的论文必须在 introduction 里讲清这个谱系，避免"another Dirichlet method"的指责；
  2. S-BKI 的 variance 隐含了 vacuity 概念（$S = \sum \alpha^k$ 小则 vacuity 高），但 S-BKI 没有用它做 OOD/LC/decay——这正是 EvidLife-Map 的差异化定位；
  3. S-BKI 是 RQ1 最 fair 的 hand-crafted baseline，ConvBKI 是 learnable baseline。两者必须都跑。
