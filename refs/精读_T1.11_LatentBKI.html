1 背景：BKI 与 VL mapping 的"两个孤岛"

LatentBKI 来自 UMich CURLY lab，是 ConvBKI [4] / Gan-BKI [16] 同一团队的延伸。其核心动机非常清晰：把闭集 BKI 推广到开放词汇，同时保留 quantifiable uncertainty。

1.1 两条平行线

  • continuous semantic mapping（BKI 家族）：Doherty [15]、Gan-BKI [16]、ConvBKI [4][29]、Ewen [17]——闭式 Bayesian update + 量化的 uncertainty，但限定固定 K 类；
  • open-dictionary VL mapping：VLMap [10]、ConceptFusion [13]、NLMap [12]、CoW [9]——支持 language query，但用 moving average，无 spatial smoothing、无 uncertainty。

1.2 LatentBKI 要解决的问题

"While [BKI] yields an efficient probabilistic update, [it] has not been studied as a possible solution for open-dictionary mapping... we propose an extension of continuous mapping to the latent space of neural networks called LatentBKI, which enables open-dictionary continuous mapping with spatial smoothing and quantifiable uncertainty." —— §I
🎯 一句话定位
LatentBKI = 把 BKI 的 likelihood 从 Categorical 换成 multivariate Gaussian，conjugate prior 从 Dirichlet 换成 Normal-Inverse-Wishart，使得 voxel 存的是 latent expectation $\mu_*$ + covariance $\Sigma_*$，可以闭式更新 + 用语言 prompt 解码 + 量化不确定性。

3 预备：BKI、Nadaraya-Watson、conjugate prior

3.1 BKI 是什么

BKI（Bayesian Kernel Inference，Vega-Brown et al. 2014 [20]）是 Gaussian Process 的近似——避开 $O(N^3)$ 复杂度，用一个 kernel $k(x_i, x_*)$ 定义 "extended likelihood"：

$$p(y_i \mid x_i, \theta_*, x_*) \propto p(y_i \mid \theta_*)^{\,k(x_i, x_*)} \tag{5}$$

kernel 只要满足 $k(x, x) = 1$ 和 $k(x, x_*) \in [0, 1]$ 即可。

3.2 Nadaraya-Watson kernel 估计

$$\hat{G}_x = \frac{\sum_{i=1}^N k(x - x_i)\, G_i}{\sum_{i=1}^N k(x - x_i)} \tag{2}$$

LatentBKI 的核心 remark：它的 latent 期望 $\mu_*^t$ 公式形式上就是 Nadaraya-Watson + Bayesian conjugate prior，所以"自带" spatial smoothing。

3.3 Normal-Inverse-Wishart（NIW）conjugate prior

Multivariate Gaussian 的 conjugate prior，参数化未知的 $\mu, \Sigma$：

$$p(\mu_*, \Sigma_*) = \mathcal{N}\!\left(\mu_*;\, \mu'_*,\, \frac{\Sigma_*}{\lambda_*}\right) \cdot \mathcal{W}^{-1}(\Sigma_*;\, \Psi_*,\, v_*) \tag{4}$$
参数含义
$\mu'_*$mean 的先验期望
$\Psi_*$covariance 的先验期望（scale matrix）
$\lambda_*, v_*$对 mean / covariance 估计的"信心"（论文中 $\lambda_* = v_*$）

5 Latent map representation（NIW）

5.1 voxel state

每个 voxel $*$ 位于 $x_*$，存四个参数 $\{\mu'_*, \Psi_*, \lambda_*, v_*\}$（NIW 的超参）。$\lambda_* = v_*$ 简化为标量"观测计数"。初始化 $\lambda_* \approx 0$ 表示 non-informative prior。

5.2 Gaussian likelihood over latent

$$p(y_i \mid \mu_i, \Sigma_i) = \mathcal{N}(y_i;\, \mu_i, \Sigma_i)$$

5.3 Bayes 后验

$$p(\theta_* \mid x_*, D) \propto p(D \mid \theta_*, x_*)\, p(\theta_* \mid x_*) \tag{3}$$

5.4 NIW prior

$$p(\mu_*, \Sigma_*) = \mathcal{N}\!\left(\mu_*;\, \mu'_*,\, \frac{\Sigma_*}{\lambda_*}\right) \cdot \mathcal{W}^{-1}(\Sigma_*;\, \Psi_*,\, v_*) \tag{4}$$
💡 为什么 Gaussian + NIW？
  • Gaussian：连续 latent space 的自然选择（CLIP 特征在 $\mathbb{R}^{512}$ 上接近 Gaussian-like，因为对比学习 + L2 normalize）；
  • NIW：是 Gaussian 唯一的 conjugate prior，可以闭式更新；
  • 对比 ConvBKI 用 Dirichlet-Categorical（适合 K 类离散），LatentBKI 是连续推广。

6 扩展似然 + sparse kernel

6.1 Extended likelihood（BKI 核心）

$$p(y_i \mid x_i, \theta_*, x_*) \propto p(y_i \mid \theta_*)^{\,k(x_i, x_*)} \tag{5}$$
$$p(y_i \mid \theta_*, x_i, x_*) = \mathcal{N}\!\left(y_i;\, \mu_*,\, \frac{\Sigma_*}{k(x_i, x_*)}\right) \tag{6}$$

kernel 起两个作用：(a) 权重远点；(b) 让远点的"虚拟方差"放大，相当于看作 noisy 观测。

6.2 Sparse kernel（Melkumyan & Ramos [33]）

$$k(d) = \begin{cases} \dfrac{1}{3}\left(2 + \cos\!\left(2\pi \dfrac{d}{l}\right)\right)\left(1 - \dfrac{d}{l}\right) + \dfrac{1}{2\pi}\sin\!\left(2\pi \dfrac{d}{l}\right), & d < l \\[6pt] 0, & d \geq l \end{cases} \tag{7}$$

论文用 $l = 0.5$ m 与 ConvBKI 一致；voxel 分辨率 0.1 m（与 ConvBKI 一致）/ 0.05 m（VLMap 对比时与 VLMap 一致）。

6.3 Spatial update

$$p(\theta_* \mid x_*, y_{1:N}, x_{1:N}) \propto \left[\prod_{i=1}^N p(y_i \mid \theta_*, x_i, x_*)\right] p(\theta_* \mid x_*) \tag{8}$$

7 地图更新：闭式 Bayesian update

这是 LatentBKI 的"机器"——四行代码完成一次 voxel 更新。

7.1 累积核权

$$\bar{k}_* = \sum_{i=1}^N k(x_*, x_i)$$

7.2 confidence 更新

$$\lambda_*^t = \lambda_*^{t-1} + \bar{k}_*$$

7.3 weighted mean

$$\bar{y}_* = \sum_{i=1}^N \frac{k(x_*, x_i)}{\bar{k}_*}\, y_i, \quad \mu_*^t = \frac{\lambda_*^{t-1}\, \mu_*^{t-1} + \bar{y}_* \bar{k}_*}{\lambda_*^t}$$
📌 Remark 1（论文原文）
"We note that the formulation of the new mean resembles the Nadaraya-Watson estimate mentioned in Section III-A." —— $\mu_*^t$ 形式上就是带先验的 N-W kernel 平均，所以 LatentBKI 是 N-W kernel + Bayesian conjugate update 的"原理化版本"。

7.4 covariance 更新（关键的三式）

$$\bar{E}_* = (\bar{y}_* - \mu_*^{t-1})(\bar{y}_* - \mu_*^{t-1})^T \tag{9}$$ $$\bar{S}_* = \sum_{i=1}^N k(x_i, x_*)(y_i - \bar{y}_*)(y_i - \bar{y}_*)^T \tag{10}$$ $$\Psi_*^t = \Psi_*^{t-1} + \bar{S}_* + \frac{\lambda_*^{t-1}\bar{k}_*}{\lambda_*^t}\, \bar{E}_* \tag{11}$$

这 3 行就是 covariance 的全部更新——加上 (7.1)~(7.3)，每帧只要 4 行就完成 latent BKI 一步。

8 Inference：Student-t 期望 + LSeg-style decoding

8.1 Posterior predictive

$$p(y_* \mid x_*) = t_{\lambda_*}\!\left(\mu_*,\, \frac{\lambda_* + 1}{\lambda_*^2}\,\Psi_*\right) \tag{12}$$

多元 Student-t 的期望和协方差：

$$\mathbb{E}(y_*) = \mu_*\quad (\lambda_* > 1)$$ $$\mathrm{Cov}(y_*) = \frac{\lambda_*}{\lambda_* - 2}\!\left(\frac{\lambda_* + 1}{\lambda_*^2}\,\Psi_*\right)\quad (\lambda_* > 2)$$

8.2 Open-dictionary decoding（LSeg-style）

给一组短语 $W$，每个 $w \in W$ 编码为 CLIP 向量 $F_w \in \mathbb{R}^{512}$。voxel 的预测类别：

$$\hat{w} = \arg\max_w \frac{F_w^T\, \mu_*}{\|\mu_*\|_2\, \|F_w\|_2} \tag{13}$$
💡 Remark 2（论文原文）
"While we present the decoding for open-dictionary queries, LatentBKI can be decoded into any format using neural network decoders." —— 这是 LatentBKI 的泛化卖点：voxel 的 $\mu_*$ 是语义中性的 latent，可以任意决策。这与 OpenVox 把 caption 特征绑死在 codebook 上不同。

9 Uncertainty Quantification（E/D-optimality 与 sampling）

9.1 三种方法

① Sampling

对 voxel feature $y_*$ 多次采样 → 解码 → 取预测方差。准确但慢（5661 ms / 10K voxels）。

② E-optimality

$U_* = \max(\lambda)$，最大特征值。论文实测与 sampling 高度相关 + 仅 2.3 ms。

③ D-optimality（式 14）

$U_* = \exp\!\left(\frac{\sum_{i=1}^C \log \lambda_i}{C}\right)$，覆盖椭球体积。

选择建议

论文推荐 E-optimality：与 sampling 相关性最强 + 速度 2461× 快。

9.2 实证（Fig. 4 sparsification plot）

移除 most uncertain points → 看 segmentation accuracy 是否上升。Sampling / E-opt 两者都强相关；D-opt 略弱。这说明 LatentBKI 的 latent uncertainty 能映射回 decoded space 的预测错误，UQ 有意义。

9.3 定性（Fig. 5, 7）

"vertically placed mattress"、"室间边界"是高方差区。Fig. 7 的关键观察：LSeg 在同一面墙上的"床"预测跨帧不一致，LatentBKI 通过 NIW 累计 → 最终"床"区域 query 高响应 + 高 uncertainty 同时存在——即"我知道这里有 bed，但我没把握"。这是 OpenVox/VLMap 都做不到的。

10 PCA 压缩：512 → 64 维

10.1 两个近似

  1. 对角协方差近似：只保 $\Sigma$ 对角元，丢 cross-correlation。类似 VAE 的对角后验；
  2. PCA 降维 512 → 64：用 PCA（affine 变换）压缩 latent，update 在压缩空间做，inference 时通过 PCA upsampling 还原。

10.2 影响

Tab. I 显示 indoor mIoU 16.69 → 16.15（PCA 引入 0.54 的小掉点）；outdoor 反而 61.26 → 61.54。论文写："generalizable to new scenes with minimal performance loss"。

📌 工程意义
512 维 NIW 的 covariance 矩阵是 $512^2 = 262144$ 个 floats / voxel，不可接受。压到 64 维 + 对角，单 voxel 只存 64 (mean) + 64 (diag cov) = 128 floats。对于 0.05m 分辨率的 indoor 100㎡ 房间 ~ $8 \times 10^5$ voxels，总开销 ~ 400 MB（可控）。

14.1 设置

iPad + Record3D 软件采集 RGB-D + pose → LSeg → LatentBKI → 公寓地图。Fig. 6 演示 open-dictionary heat-map query。

14.2 Fig. 7 关键发现

对一个"垂直放置的床垫"（罕见姿态），LSeg 跨帧出不一致的语义预测。LatentBKI 一方面给出 consistent 的 "bed" query 高响应（聚合了多视角观测），另一方面把这个区域标为 high uncertainty（提醒下游"输入很噪"）。

15 方法优势与代价

✅ 论文显式声明的优势
  • Open-dictionary + uncertainty 双重：之前两者只能二选一；
  • 闭式更新：BKI 的"金属骨架"延续；
  • vs VLMap 35× 加速（122 vs 4326 ms / 100K 点）；
  • vs ConvBKI 性能等价（验证 latent 推广无损）；
  • 3 种 UQ 选择（sampling / E-opt / D-opt）；
  • open-source。
⚠️ 论文没说但能看到的代价
  • PCA 引入信息损失：indoor mIoU 16.69 → 16.15（虽小但确凿）；
  • 对角协方差近似：丢 cross-correlation；
  • 每 voxel 仍要存 64+64 = 128 floats（vs ConvBKI 的 K 个 floats，K=20 时大 6.4×）；
  • uncertainty 在 latent space，需要 decoding；E-opt 给的不是直接 class-probability uncertainty；
  • 无 lifelong / decay：和 OpenVox 一样未涉及；
  • 无 instance level：纯 voxel-class（latent decoded class），没有"物体"概念；
  • 无 loop closure：依赖外部 pose（iPad ARKit）。

16 局限与未来工作（§V）

16.1 论文自述

"LatentBKI does not consider the unique geometry of objects and can therefore be combined with architectures such as ConvBKI, which learns per-category kernels, or the high-quality 3D Gaussian Splatting [41] novel view synthesis method which represents the environment using 3D ellipsoids, similar to the kernel structure we leverage for continuous mapping." —— §V

16.2 三条 future works

  1. per-category kernel：借鉴 ConvBKI；
  2. combine with 3D Gaussian Splatting / LangSplat；
  3. 结合 SAM 解决 boundary 问题；
  4. uncertainty 用于 active perception（与 [18], [19], [25] 衔接）。

16.3 我们读出来的关键缺口

  • 无 lifelong / dynamic：与 OpenVox 同；
  • uncertainty 是 latent / aleatoric，不是 epistemic 标量——这是关键差异（见 §17）；
  • 无 open-set rejection 机制：cosine $\arg\max$ 永远会给一个类，不会说 "I don't know"。

17.2 §9 — 与 EvidLife-Map 的关系（技术诚实版，~370 字）

LatentBKI（Wilson et al., RA-L 2025）出自 CURLY lab，与 ConvBKI（T1.4）同一作者；二者关系是"BKI 在 latent space 的连续推广"。这对 EvidLife-Map 提出一个关键 reviewer 问题："为什么不上 latent space？" 我们的辩护要严密：

(i) uncertainty 的用途决定空间：LatentBKI 的 covariance $\Sigma_*$ 是在latent space，必须通过 sampling 或 E-opt 才能转为"对类预测的不确定"，而 EvidLife-Map 的 vacuity $u = K/S$ 直接在 simplex 上、与类别 prior 同度量、可直接用于 (a) open-set 拒识阈值 $u > \tau$；(b) decay 速率 $\dot{\alpha} = -\beta \cdot u$；(c) keyframe 信息增益 $\Delta H$。三个下游应用都需要"按类对齐"的不确定性，latent uncertainty 不够直接。

(ii) open-set vs open-dictionary 不是同一件事：LatentBKI 的 (式 13) cosine argmax 永远会给一个类——给它一个"火星人"的词它就会硬投到最近的类，不会说 "I don't know"。EvidLife-Map 的 closed-set + vacuity 拒识恰好补这个空白：reviewer 问到 "为何不上 latent space" 时，回答是 "latent 给你 open-dictionary 的便利，但不给你 open-set 的诚实"。

(iii) 是否能结合？ 完全可以。论文展示了 BKI 的 framework 是模块化的——把 ConvBKI 的 Categorical 换成 Gaussian 就成 LatentBKI；同理把 LatentBKI 的 Gaussian-NIW 换成 evidential head 也能跑。这是 future work 的漂亮叙事：先证明 evidential head 在 closed-set BKI 上的优势（与 ConvBKI 直接对比），然后承诺 "extending LatentBKI-style latent evidential heads" 作为后续工作。

(iv) $\eta$ 复杂度对比：LatentBKI 每 voxel 存 128 floats；EvidLife-Map 每 voxel 仅 K (~20) floats + 标量 $S$，内存约 4-6× 优于 LatentBKI。这对消费级机器人很重要。

18 总结与启示

18.1 一句话总结

"LatentBKI 把 BKI 的 Categorical-Dirichlet 换成 Gaussian-NIW，使 voxel 存 latent expectation + covariance，从而在不损性能的前提下把 ConvBKI 推广到 open-dictionary，同时通过 E-optimality 提供高效的 uncertainty 量化，并在 MP3D 上以 35× 加速和 +1.65 mIoU 同时超越 VLMap。"

18.2 三个 takeaway

  1. "BKI 是模块化骨架"——只要换 likelihood + conjugate prior，就能服务不同语义空间。这给 EvidLife-Map 一个直接路线图：evidential head 也可以接入 BKI 骨架；
  2. "uncertainty 必须能映射回决策空间"——LatentBKI 的 latent uncertainty 通过 sampling 验证有效；但simplex 上的 vacuity 是更直接的，这就是我们的位置；
  3. "PCA + 对角协方差 = 实用化神器"——512 → 64 仅损 0.54 mIoU。如果未来我们要做 latent evidential，PCA 是必须的工程要点。
