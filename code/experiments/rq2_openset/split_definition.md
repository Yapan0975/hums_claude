# RQ2 open-set split — pre-registration

Pre-registered W3 (research_plan v3 §7 P1 deliverable). Mitigates R-15.

## Primary split (14 known + 5 unknown)

Withheld classes (re-labelled to the dedicated "unknown" index at training):

| SemKITTI class id | Name             | Rationale                                |
|-------------------|------------------|------------------------------------------|
| 4                 | bicyclist        | dynamic-rare; cross-modal LiDAR shape    |
| 5                 | motorcyclist     | dynamic-rare; cross-modal LiDAR shape    |
| 9                 | other-ground     | static-rare; ground category             |
| 17                | other-vehicle    | static-rare; vehicle category            |
| 18                | truck            | static-rare; vehicle category            |

Selection rationale (research_plan v3 §4.1):
* Spans static + dynamic.
* Spans vehicle + ground.
* All five have ≥ 500 GT points per validation sequence (per
  SemKITTI statistics).
* Leaves the 14 known classes with adequate population for closed-set mIoU.

## Robustness split (16 known + 3 unknown)

Withheld: `bicyclist`, `motorcyclist`, `other-vehicle`. Stricter (fewer
unknowns); reported as a robustness check, not as the headline number.

## Reverse cross-domain (nuScenes)

Trained on SemKITTI 14-known; AUROC evaluated on nuScenes-LiDARSeg points
labelled `construction_vehicle`, `barrier`, `traffic_cone`,
`pushable_pullable` — none have a SemKITTI analogue.

## Why pre-register

R-15 (research_plan v3 §6): a reviewer can otherwise argue we cherry-picked
the easy split. The class list above ships in supplementary as a JSON file
generated by `experiments/rq2_openset/build_split.py` (W3 task).
